## 1. 离线测试（`server: DB_PATH=… node --test ../tests/*.test.js`）

39 用例覆盖 handoff §5 全部要求维度：

- **持续性**：同一具体处境在多次 JEV 决策中持续携带证据与最新档案（journey-core「持续动机」）；同 `creature_id` 再出发换 `journey_id` 与新动机版本（contact「同一生物再出发」）；识别不可用记 `degraded`/`insufficient_evidence` 不伪装人格。
- **动作与事实**：JEV 实际选择落库 `decision_source='jev'`；结算不改写已选行动（JEV 一致性检查 + 测试断言 outcome 对应 a1）；下一遭遇提案 prompt 必须携带已提交事实与机制卡；无合适动作（none_fit）→ 每遭遇至多一次定向重提案 → 程序如实搁下；导演矛盾/模型超时/重试有确定行为（退避→暂停）。
- **联系与寿命**：信号→按时补给（进入尚未提交的决策，补给以"证据非命令"进入 JEV 输入）；不回复→到期唤醒同一遭遇→JEV 原候选决策；迟到回复只作后续参考不改写；阶段来信→继续→`is_final` 收束信→`ended_natural`；用户结束立即生效（<3s）且不再产生事件/模型调用；可控时钟证明无固定终局延迟、调度不依赖页面、静默护栏与安静时段投递有效。
- **去重与幽默**：同模板换主语被字面识别并触发一次重提案（每遭遇 ≤1 次）；"旧后果带来新取舍"不误杀；字面施压/贬低拦截；JEV 判定虚构用户事实→修订一次→坏版本永不公开；语气变更只改未来提案基调，事实追加式不被覆写。
- **并发与安全**：乐观锁冲突、一次性提交（decide/attachSupply/freeze 各只能成功一次）、租约崩溃恢复、公平取用、越权/伪造 cookie 一律 404、H5 转义静态检查、world pulse 无用户原话、JEV 不可用时**不存在**规则回退的伪 JEV 来源。

## 2. 真实生产路径验证（`node scripts/verify-journey-v2.js`，第 5 轮全过）

环境：子进程真实服务器（隔离 tmp SQLite）+ `.env` 真实凭证（千帆 `deepseek-v4-flash-0731` + typesafe JEV）；节奏 `J_TIME_SCALE=600`（部署配置缩放；所有决策均为真实模型产物，无测试专用决策逻辑）。

| 场景 | 结果 | 要点 |
| --- | --- | --- |
| A 完整旅程 | ✅ | 真实开局（goal「找到一块只属于我自己的安静角落，不用回应任何鱼」）→ 动机 `recognized` → 4 次真实 JEV 行动+结算 → 事件预算自然收束 → `is_final` 收束信（内容承接已提交事实：柳叶箭头/铜钱借条/断桥南面） |
| B 同一生物再出发 + 用户结束 | ✅ | 同 `creature_id` 新 `journey_id` 新动机文本；主程被真实 JEV 自主收束后，第三程开局即测用户结束：`ended_user` 生效延迟 **2ms**，之后零事件零调用 |
| C 不回复信号 + 跨重启 | ✅ | SIGTERM → 同 DB 重启后继续；真实 JEV 选择直接行动并完成 4 事件自然收束（如实记录：本轮无真实信号，见 §4） |
| A2 重启后旧旅程 | ✅ | `ended_natural` 稳定可读、零新事件 |

**决策来源审计**（12 个已结算遭遇）：`jev` × 11、程序搁下（none_fit）× 1；全部 `outcome_status='ok'`（JEV 一致性复核通过）；无任何模板/规则回退来源；无可疑换皮留标。

**定向补验（`scripts/verify-stage-letter.js`，阶段来信专项）**：`J_MAX_EVENTS=10` 给真实 JEV 连续 9 个中途联系检查点，它**全部自主选择"继续"**，事件预算耗尽后由 `event_budget` 走收束信（10 事件、`ended_natural`、1 次真实信号按时补给）。原始数据：`docs/journey-v2-eval/stage-letter-attempt.json`。

**模型用量（本轮 62 次调用，0 错误）**：输入 ≈ 73.7k tokens、输出 ≈ 21.6k tokens；LLM 累计时延 ≈ 175s、JEV ≈ 14s。按 kind：opening×4、jev_decide×11、settlement×12、jev_settlement_check×11、proposal×8、dedup_reproposal×8（含真实模型提案重试）、final_letter×3+repair×1、jev_letter_check×4。注意：dedup_reproposal 占比较高，源于真实模型提案与已发生机制卡部分重叠时的合规重写——属设计内行为（每遭遇限一次）。

韧性实证：真实模型偶发提案 JSON 截断/字段缺失 → 归一化 + 携带错误的定向修订 + 任务退避重试全部自愈，旅程未中断。

## 4. 未验证 / 部分验证（如实声明，不勾完成项）

1. **真实模型未产出非终局阶段来信（仅离线验证覆盖）**：累计 6 次真实完整旅程（验证主轮 5 次 + 专项补验 1 次，后者给出连续 9 个中途检查点），真实 JEV 在所有联系检查点均自主选择"继续"或直达收束信，从未选择"寄阶段来信"——因此**非终局阶段来信的写入（`letter_write`）真实链路未被真实模型覆盖**——收束信（`final_letter_write`+修复×1）及其程序+JEV 边界检查已有真实文本通过，缺的是检查点选择"寄阶段来信"这一步本身。阶段来信相关行为仅由离线套件（桩 LLM/JEV）完整验证。handoff §5 验收链路中"非终局经历来信 → 继续行动"一段在真实路径上缺此一环，如实列明、不勾完成项；阶段来信的产品/提示词设计（何时更倾向写信）留待人工盲评与后续调参。
2. **真实信号链路部分覆盖**：验证主轮的 5 次真实旅程中真实 JEV 均选择直接行动；随后盲评材料生成与专项补验中各出现 1 次**真实信号**（如"石头被苔藓写了 EXIT……你说，我是该装睡还是假装路过？"——无施压、要一句话补给），并经脚本按时补给后由真实 JEV 决策直至自然收束。即：信号撰写→按时补给→真实决策已由真实模型走通；**"到期无补给"分支仍仅离线覆盖**（真实 JEV 未在观察窗口内给出该形态样本）。
3. **人工盲评未做**：同一处境 3 份匿名材料已生成（blind-eval/），换皮识别率、因果自然度、好笑程度、被尊重感、继续阅读意愿均**无人评结论**；旧 `docs/jev-validation.md` 的 16 样本模型代理对照不作为本版效果证据。
4. **配图质量未评**：验证轮 `J_IMAGE_BUDGET=1` 已配置；本轮收束信配图未触发人工查看，仅代码路径被离线测试覆盖。
5. **`outcome_status='unverified'`**（JEV 故障时结算无一致性复核）在真实轮未自然出现，仅离线测试覆盖。
6. 深度语义换皮（改写措辞的机制重复）依赖边界带 JEV 窄比较，真实轮未出现该形态样本；字面层已验证。
