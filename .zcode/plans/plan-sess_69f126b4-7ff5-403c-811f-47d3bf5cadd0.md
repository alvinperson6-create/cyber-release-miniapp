# 赛博放生 · 3D 地球化 + 年度最佳向全面升级（新分支探索）

**新分支名：`feature/3d-globe-v3`**（从 main 切出，不动现有产品内核：情绪放生 → 延迟 AI 回信 → 命运轨迹广告解锁的数据流、API、db 结构完全不变）

## 一、3D 地球放生（两端同步）

### 网页版（web-app.html，主战场）
1. 引入 Three.js（CDN + 本地 fallback `server/public/vendor/three.min.js`，保持离线可用）
2. 新增 3D 地球场景替换现有 2D 平面地图：
   - 水色渐变球体（shader：深海洋流噪声动画 + 生物发光边缘光）
   - 12 个水域 = 球面上的发光水域标记（经纬度映射，复用 WATER_COORDS 转换）
   - 大陆用低多边形（low-poly）浮出或用发光海岸线勾勒
   - 拖拽旋转 / 惯性 / 双指缩放；选水域时球体自动旋转对准（复用 panToWater 的居中逻辑改为球面插值）
3. 放生动画 3D 化：生物（3D 化的锦鲤/龟/云，用简单几何体 + 着色器风格化）沿贝塞尔弧线俯冲潜入水域，水面泛起涟漪 shader + 气泡粒子 + 光柱
4. 性能：requestAnimationFrame 循环、页签隐藏暂停、devicePixelRatio 上限 2

### 小程序端（miniprogram/pages/release）
1. 使用官方 `threejs-miniprogram` 适配层 + canvas type="webgl"，封装独立 3D 组件 `components/globe3d/`
2. 与网页版共享同一套：水域经纬度表、生物 3D 参数、动画时序常量（抽到 `utils/globe-config.js`，构建脚本同步到 web 用的 JSON）
3. 降级策略：WebGL 初始化失败 / 低端机自动回落到现有 CSS+SVG 地图（保留现有代码为 fallback 分支）

## 二、仪式感拉满（放生瞬间）
- **长按蓄力放生**：按住按钮生物逐渐发光、心跳震动（wx.vibrateShort 网页端 Navigator.vibrate），松手送出——替代现有单击
- **呼吸节奏引导**：放生前 3 秒呼吸圈引导（"吸气…呼气…放手"文案）
- **音效**：水声入水、涟漪、回执盖章音（小程序 wx.createInnerAudioContext；网页端 WebAudio 合成，不加外部音频文件）
- **放生瞬间海报**：回执页生成可保存/分享的专属海报（canvas 绘制：生物剪影 + 水域 + 护生编号 + 好运签 + 当天星象风格背景）

## 三、回信升华
- **漂流瓶拆封**：回信到达后不是直接展示，而是先出现一个 3D 漂流瓶浮出水面，用户点开/上滑拆封，信纸展开动画
- **AI 语音朗读**：后端新增 TTS（接入现有 OpenAI 兼容协议，优先微信同声传译插件做小程序端、后端 TTS 做网页端），生物专属音色
- **回信卡片 3D 展示**：AI 配图卡片带视差倾斜（陀螺仪/鼠标移动）

## 四、世界感 / 社交
- 后端新增 `GET /api/world/pulse`：返回全球累计放生数、最近匿名放生片段（一句情绪 + 生物 + 水域，不含隐私）
- 3D 地球上实时显示"此刻共有 N 条生命在流浪"，其他用户刚放生的位置在球面上短暂亮起一颗光点
- 「年度放生报告」页：放生次数、最远到达的离谱地点、最常陪伴的生物、收到最戳的一句回信（本地/后端聚合）

## 五、命运轨迹升级
- 轨迹页改为**航线图**：地图/球面上从放生水域到 AI 离谱结局地点画出动线（网页端 3D 球面弧线；小程序端 2D 地图弧线动画），每解锁一段，航线延伸一段 + 抵达新地点光爆效果
- 后端 destiny 数据已含 location 字段，无需改库；新增地点→经纬度查表（LLM 生成时要求输出标准地名，加一个常见地名坐标表 + 兜底随机坐标）

## 风险与约束
- 小程序 WebGL 包体积与性能：threejs-miniprogram 按需裁剪，低端机自动降级 2D
- 单文件 HTML 原则：three.js 走 CDN + 本地 vendor fallback
- `.env` 明文 key 问题顺带迁移到环境变量注入（不改行为）
- 所有改动不动 records/destinies 表结构与既有 API 语义，只新增接口
